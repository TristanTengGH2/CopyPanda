# Overlay v1

Version `1.0.0-preview.1` is the first Windows prototype snapshot, preserved
on the `overlay-v1` branch as well as in the main repository history.

- Transparent panda overlay with occasional page turns and pause/resume timer.
- Full-minute leaf earnings, small completion bonus, and reward-free demo.
- Calendar with month names, today's outline, and dots below recorded dates.
- Notes, study goals that preserve progress across missed days, and exit bookmarks.
- Labeled navigation icons and leaf icons beside balances.
- Transparent desktop layout editor with proportional resizing, Save, and Cancel.
- Circular four-arrow drag handle on the overlay and a minimize control in the timer row.
- Buttons, icons, text, and the panda scale together; controls remain within the window.
- Local save backup/recovery and Windows session/power-event helper.
- Reduced motion, larger text, contrast, and always-on-top options.
- Simplified red-panda face for the application and notification-area icon.

This is a portable, unsigned preview. Networking, QR rooms, synced timers,
cosmetics, browser/native data sync, signed installation, and automatic
updates are not included. Real lock/sleep and mixed-DPI hardware testing
remain necessary before a wider release.
