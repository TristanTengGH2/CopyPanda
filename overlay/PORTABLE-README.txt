CopyPanda 1.1.0-preview.1 - Windows x64 preview

Extract the whole folder, then run CopyPanda.exe. Keep CopyPanda.pck and
CopyPanda.SessionEvents.exe beside it. This alpha is not code signed.

Use Menu > Settings > Adjust overlay to move or resize the panda on a
transparent editing layer. Drag a corner to resize everything together,
then choose Save position. Cancel or Escape keeps your previous layout.
Hide keeps your timer running. Restore using the panda icon in the Windows
notification area (it may be under the hidden-icons arrow).

Your study data is stored locally in %APPDATA%\CopyPanda\state.json, with
a rotating backup. Browser progress is separate. No account is required.
The small session helper handles Windows lock/sleep events only and exits
with CopyPanda. It does not track keys, websites, location, or applications.

Try the 10-second demo under Menu. Demo sessions give no rewards.
This first alpha supports solo study. Friends, QR rooms, shared timers,
cosmetics, automatic updates, and browser/native sync are not implemented.
