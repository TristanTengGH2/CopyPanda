# Native artwork

`panda-page-turn-sheet.png` is a byte-for-byte copy of the selected browser
prototype's `web/assets/panda-page-turn-sheet.png`. Its generation provenance,
reference use, and six-frame registration corrections are documented in
`web/assets/ASSETS.md`. The overlay displays complete character frames and
does not load the cafe background or foreground furniture.

`icon.svg` is a simple project-drawn red-panda placeholder for the window/tray.
It is not the final logo. The visible study panda uses the approved sprite sheet.

`panda-break-sheet.png` is the built-in imagegen break-state sheet shared with the web app. Its exact prompt and reference roles are recorded in `web/assets/ASSETS.md`. Break mode switches to its relaxed first pose immediately and uses the stretch sequence for occasional motion.
