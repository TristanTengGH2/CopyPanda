The user supplied a ZIP of red-panda illustrations and warm miniature-room images as visual references. Those source images are not included in this repository and are not assumed to be licensed for shipping.

## Selected artwork

`cafe-flat-panda.png` was created with the built-in image-generation tool. The user selected the first flatter-panda revision. The original warm café background was preserved and its rendered panda was replaced with a flatter hand-drawn character. `panda-matched.png` is a transparent companion derived from that scene with the same tool after the user requested consistent panda styling. It is a prototype, not a production sprite sheet. The earlier round-eyed standalone mascot was rejected and is not used.

Both final files are saved in this directory, rather than referenced from the generator's private storage. The original generated files are preserved outside the repository.

## Coherent page turn and foreground corrections

The user rejected the code-drawn paper and clipped sliding paw. They are removed. The selected replacement assets below were all created with the built-in image-generation tool using the existing panda or café as references; no third-party source image is redistributed.

- `panda-page-turn-sheet.png`: six complete poses, 3 columns × 2 rows. A page of the existing botanical book turns about its spine while the sleeve and arm remain attached. CSS changes the visible cell; it does not detach a limb or introduce a second book.
- `cafe-desk-clean.png`: corrected background with the redundant left-front table support removed. Desk vine, flower vase, and mug are absent so the foreground instances cannot double with background copies.
- `desk-foreground.png`: transparent atlas containing the desk vine, flower vase, and mug. The generator arranged these as an atlas rather than retaining the requested full-scene coordinates. Three static CSS regions place them at their original desk positions above the panda. They share the background's viewport transform, so they stay aligned on resize.

The original reference assets are retained for provenance and compact-view use. The new scene also remains properly layered with reduced motion enabled; only the character movement stops.

The generated frames have small registration differences. A fixed cover/spine mask was tried and rejected because it clipped the turning page. The selected version displays complete frames without that mask. Upper-head landmark analysis found that frames 4–6 sit 2–3 source pixels higher, with 1–2 pixel horizontal offsets in other frames. Per-frame CSS translations register the intact poses to the first frame without cutting the book. Whole-character bob/rotation remains removed. Small changes in the drawn book shape can remain because these are generated poses, not a production rig.
